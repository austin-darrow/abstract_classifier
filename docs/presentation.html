CIP Classifier

Automatic field-of-science classification for TACC allocation abstracts — Sprint Review, July 2026

What is this?

We built a classifier that reads TACC allocation request abstracts and predicts their field of science according to the CIP taxonomy — the federal standard for categorizing academic programs.

The system classifies at three levels simultaneously: 22 broad fields (e.g., "Engineering"), 74 major fields (e.g., "Electrical and computer engineering"), and 315 detailed fields (e.g., "Computer Engineering, General") — all from a single model in a single forward pass.

The Architecture

One Model, Three Prediction Levels

The deployed model is a single SciBERT (a BERT variant pre-trained on 1.14M scientific papers) fine-tuned to output 315 detailed-field probabilities. From those 315 numbers, we derive major-field and broad-field predictions purely via math — no second model needed.

How Inference Works (Step by Step)

StepWhat Happens
1. Encode Abstract is tokenized and passed through SciBERT → 768-dimensional vector representing its meaning
2. Classify Linear layer maps 768-dim vector to 315 logits (one per detailed CIP field)
3. Softmax Convert logits to probabilities: P(detailedj) for all 315 fields, summing to 1.0
4. Marginalize Sum children to get major-field probs: P(majorm) = Σ P(detailedj) for j ∈ children(m)
5. Strategy C Final score = P(majorparent) × P(detailedj). Pick highest score.

Why Strategy C?

Multiplying each detailed probability by its parent major's probability acts as a consistency boost. If the model spreads probability across several subfields of Physics, the marginalized P(Physics) is high, reinforcing all Physics predictions. A spurious high-confidence outlier in an otherwise-unlikely field gets suppressed. This improved accuracy by +0.8% over naïve argmax on the 315 outputs.

Why Freeze Layers 0–7?

SciBERT has 12 transformer layers. The early layers capture general language features (grammar, word meaning) that are already well-learned. Freezing them prevents overfitting on our ~23K training samples while still allowing the top layers to specialize for field-of-science classification. This configuration won a 47-config hyperparameter sweep.

Training Data Pipeline

No reliably labeled real data existed, so we built training data through four complementary strategies:

SourceCountMethod
Synthetic abstracts 16,183 Generated by DeepSeek-R1 (671B) on 9 Vista GH200 nodes. Each CIP field gets ~10 abstracts with field-specific prompts. Adversarially verified against sibling fields.
Silver labels (major) 5,327 Real TACC abstracts where two independent models (SetFit + SciBERT) agree on the major field at confidence ≥ 0.7. These are pseudo-labeled real data.
Detailed silver labels 4,155 Real TACC abstracts classified by our hierarchical model at high confidence (major ≥ 0.90, detailed ≥ 0.50). Provides detailed-field annotations for real abstracts.

Total training set 23,303* *Records with detailed_field annotation (used to train the single unified model)

Synthetic Generation

Each abstract is generated with a field-specific prompt that includes the CIP title, definition, and sibling fields to avoid. The generation pipeline uses DeepSeek-R1 (671B parameters, FP8 quantized) served across 9 Grace-Hopper nodes via vLLM + Ray. Post-processing strips <think> blocks, preamble/postamble, and rejects abstracts that contain meta-language ("as instructed", "here's a", etc.). An adversarial verification step then checks that the abstract is distinguishable from sibling fields.

Targeted Generation for Weak Fields

After initial training, 15 fields had F1 < 0.80. Rather than generating a flat 100 per CIP (which would give Engineering Technologies 6,900 samples vs. 200 for small fields), we used dynamic per-field targeting: calculate how many each field needs to reach 300 total, then distribute evenly across its CIP programs. Result: +7% average F1 across the 15 target fields, with Mechanical Engineering improving +36%.

Key Decisions

  • Single model over two-model hierarchical: Only 1% accuracy difference, but dramatically simpler deployment (one model, one forward pass, principled marginalization)
  • SciBERT over larger models: DeBERTa-v3-large was 10× slower for <0.2% gain; SciBERT is fast enough for CPU-only deployment
  • DB labels are not ground truth: Real TACC labels are often incorrect. We evaluate on synthetic test and inter-model agreement instead.
  • Targeted per-field generation: Dynamic caps prevent class imbalance; brought weakest fields from avg 0.69 → 0.76 F1

What's Next

  • ONNX export: Convert the single model to ONNX format for 3–5× CPU inference speedup
  • FastAPI deployment: Build the API server + web UI for interactive and batch classification

  • Final manual verification: Test random real abstracts against the model to validate predictions in practice
