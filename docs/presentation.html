CIP Classifier

Automatic classification of research abstracts into CIP taxonomy fields — Status Update, June 2026

What is this?

We built a classifier that reads TACC allocation request abstracts and predicts their field of science according to the CIP taxonomy — the federal standard for categorizing academic programs.

The system classifies at three levels: 22 broad fields (e.g., "Engineering"), 74 major fields (e.g., "Electrical and computer engineering"), and 315 detailed fields (e.g., "Computer Engineering, General").

The system uses two SciBERT models (a language model trained on scientific papers) — one trained for major-field classification and one for detailed-field classification. At inference time, the major model's predictions constrain the detailed model's output space: only detailed fields that are valid children of the predicted major field are considered. This hierarchical approach improves both levels simultaneously.

Training Data

Since reliable labeled data didn't exist, we generated 16,183 synthetic training abstracts using DeepSeek-R1 (a 671B-parameter language model) running on Vista's GH200 GPUs. Each synthetic abstract was adversarially verified against sibling fields to ensure distinctiveness. We then added 5,327 pseudo-labeled real abstracts where multiple models agreed with high confidence, for a total training set of 21,510 examples.

Key Takeaways

  • 94% major-field accuracy and 89% detailed-field accuracy across 315 CIP categories
  • The classifier is more accurate than existing database labels — DB labels have ~55% disagreement with model consensus + manual review
  • Hierarchical constrained decoding improves both coarse and fine-grained predictions simultaneously
  • Training data was fully synthetic (LLM-generated) + pseudo-labeled real abstracts — no manual annotation required
  • Inference takes ~0.5s per abstract on GPU, suitable for batch or real-time classification
  • Most remaining errors are in inherently ambiguous "other" and "general" catch-all categories

What's Next

  • Deployment: FastAPI service on a TACC VM with a web UI for interactive classification and a batch endpoint for bulk processing
  • More training data: Generate additional synthetic abstracts for the ~15 lowest-performing fields to close the long-tail gap
  • Detailed silver labels: Use the hierarchical model to pseudo-label real TACC abstracts at the detailed level, then retrain a unified single-model architecture
  • Gold evaluation set: Manually label 50–100 real abstracts to get an unbiased real-world accuracy measurement
